# МедШкалы СМП 🏥

Приложение для расчёта клинических прогностических шкал на вызове скорой медицинской помощи.

## Шкалы

| Шкала | Назначение |
|-------|-----------|
| **qSOFA** | Экспресс-оценка риска сепсиса (3 критерия) |
| **NEWS2** | Шкала раннего предупреждения (6 параметров) |
| **Wells** | Предтестовая вероятность ТЭЛА |
| **GCS** | Шкала комы Глазго — оценка сознания |

## Скачать APK

Перейди в раздел **[Releases](../../releases)** → скачай `app-debug.apk`

## Сборка через GitHub Actions

1. Сделай **Fork** этого репозитория
2. Перейди во вкладку **Actions** → разреши выполнение workflows
3. Сделай любой коммит (или запусти workflow вручную через `workflow_dispatch`)
4. После сборки APK появится в **Releases**

## Установка на Android

1. Скачай `app-debug.apk` с телефона
2. Разреши установку из неизвестных источников:  
   `Настройки → Безопасность → Неизвестные источники`
3. Открой скачанный файл → Установить

## Технические детали

- **Язык:** Kotlin + WebView
- **minSdk:** Android 7.0 (API 24)
- **targetSdk:** Android 14 (API 34)
- **Работает офлайн** — все данные встроены в приложение
- Размер APK: ~4–5 МБ
